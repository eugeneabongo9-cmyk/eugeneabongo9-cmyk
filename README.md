# Hi, I'm Vita No Yami 👋

**Builder of production systems and intelligent tools**

I spend most of my time turning ideas into software that holds up under real use. That usually means writing the backend that has to stay fast and correct, connecting it to whatever interface people actually touch, and making sure the whole thing can be maintained after the first version ships.

Lately that work has centered on systems that understand language — local models that answer questions about data, agents that can act on those answers, and the surrounding services that keep everything reliable. I also still enjoy lower-level work: job queues that don’t drop messages, APIs that stay predictable, and the occasional game or interactive experiment when I want to think differently about state and feedback.

I tend to stay close to the code from the first sketch through deployment. The best results I’ve seen come from treating reliability and clarity as features, not afterthoughts.

---

### What I’m working on
- Agents and natural-language layers that sit on top of real databases and business data
- Async and background processing that stays predictable under load
- Membership platforms, SaaS pieces, and the infrastructure around them

### Tools and languages I reach for
TypeScript, Python, Rust, and Go for most day-to-day work. FastAPI and Cloudflare when I need something online quickly. Tokio and Redis when the work is more systems-oriented. Local models (Ollama and friends) when the product needs language understanding without sending everything to a remote API. SvelteKit or Next.js for the interface side. Godot when I want to build something interactive that isn’t a web form.
